# Sounds for Omkar's Mountain Café

Put these files in a folder called `sounds` next to `index.html`:

```
OmkarJadhav2020.github.io/
├── index.html
└── sounds/
    ├── wind.mp3  ...
```

Any file that's missing falls back to the built-in generated sound, so the site never breaks.

Tips
- Pixabay sounds are free to use with no credit required. Check the license on each page.
- Keep loop files short (30 s–2 min) and each file under ~1–2 MB.
- Rename each download to exactly the file name above.
- Test locally with a small server (e.g. VS Code "Live Server"), since browsers may block audio from file:// pages.
